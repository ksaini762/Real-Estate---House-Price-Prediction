# 🏠 Real Estate - House Price Prediction

A machine learning project that predicts housing prices based on various features such as crime rate, number of rooms, accessibility to highways, and more.  
This project uses regression models trained on the Boston Housing dataset.

---

## 📌 Features

- 🧾 Reads and processes real estate data from CSV
- 📊 Exploratory Data Analysis (EDA) with Pandas & Matplotlib
- 🧠 Trains regression models using Scikit-learn
- 📈 Evaluates models with R², MSE, and visualization
- 🧪 Includes testing and validation notebook

---

## 🛠️ Tech Stack

- **Python**
- **Pandas, NumPy**
- **Matplotlib, Seaborn**
- **Scikit-learn**
- **Jupyter Notebook**
